# 需求文档

版本: 1.3.0
更新时间: 2026-02-07 10:30:00

---

## 1. 目标

为 `simple-mind-map（https://github.com/wanglin2/mind-map）` 增加登录、云端存储、展示、分享功能，打造一个完整的在线思维导图服务。

---

## 2. 用户角色

| 角色 | 说明 |
|------|------|
| 游客 | 未登录用户，只能访问分享链接查看思维导图 |
| 注册用户 | 已通过 GitHub 登录的用户，可创建、编辑、保存、分享思维导图 |

---

## 3. 功能需求

### 3.1 登录功能

为 `simple-mind-map` 项目增加登录功能，未登录时用户只可见登录弹窗。

**登录方式**:
- 使用 GitHub OAuth 登录
- 登录成功后获取用户基本信息（头像、昵称、GitHub ID）

**登录流程**:
1. 用户点击登录按钮
2. 跳转 GitHub OAuth 授权页面
3. 用户授权后回调到应用
4. 后端验证并创建/更新用户记录
5. 返回 JWT Token 用于后续鉴权
6. 前端存储 Token 并跳转文件列表页

**会话管理**:
- Token 有效期：7 天
- 支持主动退出登录
- Token 过期自动跳转登录页

---

### 3.2 文件列表展示

用户登录成功后，落地到文件列表页面，页面中展示用户已保存的文件。

**列表功能**:
- 使用卡片方式展示已有文件
- 第一个卡片始终是【创建新思维导图】
- 支持按创建时间/更新时间/文件名排序
- 支持按文件名搜索

**卡片信息**:
- 思维导图缩略图（自动生成的预览图）
- 文件名称
- 创建时间
- 更新时间
- 文件大小
- 分享状态图标

**卡片操作**:
| 操作 | 说明 |
|------|------|
| 点击卡片 | 进入编辑页面 |
| 重命名 | 修改文件名称 |
| 删除 | 删除文件（需二次确认） |
| 开启/关闭分享 | 切换分享状态 |
| 复制分享链接 | 复制到剪贴板 |

**文件上传**:
- 支持从本地上传 `.smm` / `.json` 格式的思维导图文件
- 上传入口位于文件列表页面
- 上传时校验文件格式和大小限制

**空状态**:
- 无文件时显示引导创建提示

---

### 3.3 思维导图编辑

用户在文件列表点击【创建新思维导图】或已有文件卡片，跳转到思维导图编辑界面。

**编辑界面**:
- 基于 `simple-mind-map` 的 web 目录实现
- 保留完整的编辑功能

**保存功能**:
- **云端同步**：每 30 秒自动同步一次到云端
- **本地备份**：内容变更后 1 秒自动备份到浏览器 `localStorage`（秒级防护）
- **异常恢复**：重新打开文件时，若检测到本地备份比云端更新，提示是否恢复
- **手动保存**：提供保存按钮，立即同步到云端
- 保存时显示保存状态提示
- 保存失败时提示并允许重试

**新建文件流程**:
1. 默认文件名：`未命名思维导图`
2. 首次保存时弹窗让用户输入文件名
3. 生成 UUID 作为文件唯一标识
4. 保存完成后更新 URL 携带文件 UUID

**页面导航**:
- 提供返回文件列表的入口
- 离开页面时检测未保存内容并提示

---

### 3.4 云端存储功能

用户可将当前文件保存到云端。

**存储设计**:
- 每个文件使用 UUID 作为唯一标识
- 文件内容存储在 R2 对象存储
- 文件元信息存储在 D1 数据库
- 文件格式使用 `simple-mind-map` 的标准 JSON 格式（.smm）

**文件命名冲突处理**:
- 同一用户下文件名唯一
- 重名时提示用户选择：覆盖 / 自动重命名（追加时间戳）

**屏蔽本地保存**:
- 移除/隐藏导出到本地文件的功能入口
- 只保留云端保存功能

**缩略图生成**:
- 保存时自动生成 PNG 缩略图
- 缩略图尺寸：300x200
- 缩略图存储在 R2

---

### 3.5 分享功能

#### 3.5.1 分享链接

文件的分享链接基于 UUID 生成，避免泄露文件信息。

**链接格式**:
```
https://[域名]/share/{uuid}
```

**分享控制**:
- 默认不开启分享
- 用户可随时开启/关闭分享
- 关闭分享后，分享链接失效

#### 3.5.2 分享页面（只读展示）

分享页面通过裁剪 `simple-mind-map` 的 web 目录实现。

**保留功能**:
- 思维导图展示
- 缩放、平移
- 节点折叠/展开
- 主题切换（仅查看）
- 备注查看

**移除功能**:
- 编辑功能
- 样式修改功能
- 保存功能

**新增功能**:
- 下载思维导图数据（.smm 格式）
- 显示作者信息（可选）
- 显示创建/更新时间

#### 3.5.3 私有桶访问方案

由于 R2 使用私有模式，分享页面访问文件流程：

```
用户访问分享链接
    ↓
Worker 验证分享状态
    ↓
分享有效 → Worker 使用 R2 绑定读取文件 → 返回文件内容
分享无效 → 返回 404 页面
```

## 4. 数据模型

### 4.1 用户表 (users)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT (PK) | 用户 UUID |
| github_id | TEXT | GitHub 用户 ID |
| username | TEXT | GitHub 用户名 |
| avatar_url | TEXT | 头像 URL |
| email | TEXT | 邮箱（可为空） |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

### 4.2 文件表 (files)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT (PK) | 文件 UUID |
| user_id | TEXT (FK) | 所属用户 ID |
| name | TEXT | 文件名 |
| size | INTEGER | 文件大小（字节） |
| r2_key | TEXT | R2 存储键 |
| thumbnail_key | TEXT | 缩略图 R2 键 |
| is_shared | BOOLEAN | 是否开启分享 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

## 5. API 接口

### 5.1 认证相关

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/auth/github | 发起 GitHub OAuth |
| GET | /api/auth/callback | OAuth 回调 |
| POST | /api/auth/logout | 退出登录 |
| GET | /api/auth/me | 获取当前用户信息 |

### 5.2 文件相关

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/files | 获取文件列表 |
| POST | /api/files | 创建文件 |
| GET | /api/files/:id | 获取文件详情 |
| PUT | /api/files/:id | 更新文件 |
| DELETE | /api/files/:id | 删除文件 |
| GET | /api/files/:id/content | 获取文件内容 |
| PUT | /api/files/:id/content | 更新文件内容 |

### 5.3 分享相关

| 方法 | 路径 | 说明 |
|------|------|------|
| PUT | /api/files/:id/share | 开启/关闭分享 |
| GET | /share/:id | 访问分享页面 |
| GET | /api/share/:id/content | 获取分享文件内容 |

---

## 6. 页面路由

| 路径 | 页面 | 权限 |
|------|------|------|
| / | 登录页 / 文件列表页 | 未登录显示登录，已登录显示列表 |
| /files | 文件列表页 | 需登录 |
| /edit/:id | 编辑页（已有文件） | 需登录且为文件所有者 |
| /edit/new | 编辑页（新建文件） | 需登录 |
| /share/:id | 分享展示页 | 公开（需分享开启） |

## 7. 约束条件

### 7.1 技术约束

- 部署平台：Cloudflare Workers
- 对象存储：Cloudflare R2（私有桶）
- 数据库：Cloudflare D1
- 前端框架：基于原 `simple-mind-map` 的 Vue 2.x

### 7.2 配额限制

| 项目 | 限制 |
|------|------|
| 单用户文件数量 | 不限制 |
| 单文件大小 | 10 MB |
| 用户总存储空间 | 200 MB |

### 7.3 安全要求

- 所有 API 需进行身份验证（分享接口除外）
- 文件所有权验证
- 防止未授权访问他人文件
- R2 存储桶使用私有模式，禁止公开访问

### 7.4 扩展性要求

项目应避免对原 `simple-mind-map` 的修改，以便`simple-mind-map`后续更新时，可以无缝升级。

---

## 8. 非功能需求

### 8.1 性能

- 文件列表加载时间 < 2 秒
- 编辑页加载时间 < 3 秒
- 保存响应时间 < 1 秒

### 8.2 可用性

- 支持主流浏览器（Chrome、Firefox、Safari、Edge）
- 响应式设计，支持移动端访问（仅查看）

### 8.3 可维护性

- 完善的错误日志记录
- API 接口文档
