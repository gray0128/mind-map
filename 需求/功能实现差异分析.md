# Cloud-App 与原项目功能实现差异分析

**版本编号**: v2.0  
**更新时间**: 2026-01-15 19:58:00

## 概述

本文档对比了 `cloud-app`（本项目）与 `web`（原项目）在工具栏、右键菜单、右侧工具栏等主要功能模块的实现差异。

> 本文档重点分析**相同功能的实现细节差异**以及**功能可用性**，而不仅仅是列出缺失功能。

## 5. 通用差异总结

### 5.1 国际化

- **本项目**: 所有文本为硬编码中文
- **原项目**: 使用 Vue I18n (`$t()`) 支持多语言

### 5.2 状态管理

- **本项目**: 使用 Pinia (`useMindMapStore`)
- **原项目**: 使用 Vuex (`mapState`, `mapMutations`)

### 5.3 UI 框架版本

- **本项目**: Element Plus (Vue 3)
- **原项目**: Element UI (Vue 2)

### 5.4 代码风格

- **本项目**: Vue 3 Composition API (`<script setup>`)
- **原项目**: Vue 2 Options API
